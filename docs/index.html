OnStar Token Helper

Get your Chevy/GM car back into Home Assistant when GM blocks the OnStar2MQTT add-on's sign-in.

🚫 Access Denied: GM's auth server blocked this sign-in attempt. Retrying immediately makes this worse…

If your OnStar2MQTT add-on shows this and all your vehicle entities are unavailable, this tool fixes it in about two minutes. You sign in to GM yourself, in your normal browser, and the tool installs the new token into Home Assistant for you.

Download (ZIP) View on GitHub

What happens when you click the button

  1. GM's real sign-in page opens in your browser. You sign in like normal, including the text-message code. GM sees a person, not a robot. The tool never sees your GM password.
  2. Your browser asks to open the helper. Click Open. That hands the tool a one-time code, which it trades for a sign-in token.
  3. Home Assistant collects the token. HA's built-in Downloader fetches it once from your PC. Only your HA box is allowed in.
  4. The add-on restarts and checks in. The tool watches it for two minutes. Your car's sensors come back.

Install

  • Windows 10/11 with Python 3.10+ (the standard installer includes everything except one package):
pip install websockets
  • Unzip, then double-click onstar_token_helper.pyw.
  • First run: enter your Home Assistant address and a long-lived access token (HA → your profile → Security). It's saved encrypted for your Windows user only.

Set up automatically on first run

  • The add-on's TOKEN_LOCATION moves to /share/vehicle1, because Home Assistant can only save files there. Your other add-on settings stay the same.
  • HA's built-in Downloader integration is added, pointed at /share.
  • A Windows firewall rule lets only your HA box reach port 8766 on this PC. Windows asks you once to allow it.

Good to know

  • Sign in with the same GM account the add-on uses. The tool shows the account before it continues.
  • The add-on renews the token on its own. If GM blocks it again later, just run the tool again.
  • If the add-on rejects the token, it stops after one try, and the tool turns off its start-on-boot so it won't keep retrying and make GM's block worse.
